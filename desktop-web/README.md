# WallFruits Desktop Web

## Stack
- React
- TypeScript
- Vite
- Nginx

## Objetivo
Esta e a web oficial para desktop. No celular, o usuario e redirecionado para a pagina do app nativo.

## Como rodar localmente
```bash
npm install
npm run dev
```

## Como buildar
```bash
npm run build
```
