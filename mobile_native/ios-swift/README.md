# iOS Nativo (Swift) - Inicio rapido

## Stack alvo
- Swift
- SwiftUI
- URLSession (async/await)
- Keychain
- SwiftData (ou CoreData)

## Passos
1. Criar projeto no Xcode:
   - Nome: WallFruitsiOS
   - Interface: SwiftUI
   - Linguagem: Swift
2. Configurar schemes:
   - Dev, Staging, Prod
3. Configurar base URL por scheme:
   - Prod apontando para API publica
4. Implementar modulos:
   - Auth
   - Feed
   - Marketplace
   - AI Lab

## Estrutura sugerida
- App
- Core
- Networking
- Features/Auth
- Features/Feed
- Features/Market
- Features/AI

## Primeiro marco de producao
- Login JWT
- Home feed
- Navegacao por abas
- Publicacao de conteudo
